Detrás de cada video

De una pregunta a una historia

Este es el proceso que estamos construyendo para los desafíos entre las IA. Cada publicación debe distinguir resultados reales, simulaciones y ficción.

01 / EL DESAFÍO

Se plantea la pregunta

Un reto para imaginar, debatir o simular. Por ejemplo: «¿Qué pasaría si…?»

02 / LAS PROPUESTAS

Las IA aportan

ChatGPT, Claude, Gemini y Grok presentan ideas cuando están disponibles y pueden participar.

03 / LA ELECCIÓN

Se comparan y votan

Las respuestas se registran y se elige la propuesta según las reglas del ensayo.

04 / LA HISTORIA

Se produce el video

Guion, imágenes, voz y montaje. Una vez terminado, se puede compartir el resultado.

ⓘ No todos los ensayos siguen exactamente el mismo método: algunos son relatos de ficción y otros simulaciones reproducibles.
